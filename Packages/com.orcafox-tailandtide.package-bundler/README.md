# Package Bundler

いつも入れる .unitypackage を 1 つにまとめる Unity エディタ拡張です（VRChat / Unity 2022.3）。
Bundle the .unitypackage files you always import into a single package.

- メニュー / Menu: Tools > Package Bundler
- .unitypackage 版と VCC 版は、どちらか片方だけ入れてください。
  Install either the .unitypackage version or the VCC version, not both.
